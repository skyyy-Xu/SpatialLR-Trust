# Data availability

The pilot benchmark uses public processed spatial-transcriptomics data from GEO:

- GSE300445: melanoma, 10x Visium, four samples;
- GSE283052: colorectal cancer, 10x Visium, twelve samples;
- GSE292299: NSCLC subset, 10x Visium, eighteen samples;
- GSE243168: breast cancer, 10x Xenium, three sections from two tissue blocks, used only for controlled perturbation and construct-validity analysis.

Raw and processed source matrices are not duplicated in this repository. Download locations, access notes and analytic roles are recorded in `docs/data_inventory.tsv`. The repository includes selected derived candidate, null-model, score, sensitivity and figure-source tables needed to inspect the reported computational claims.

All source datasets retain their original repository terms. No third-party dataset is relicensed by this project.
